# Student Result Management System

## Project Title
Student Result Management System

## Overview
This project is a complete multi-page PHP-based website that allows users to register, log in, and view student academic results. It includes a working contact form and a functional result management section for administrators.

## Features
- Multi-page website using HTML, CSS, JavaScript, and PHP
- User registration and login with secure password hashing
- Session-based authentication and logout support
- Result management for admin users
- Student dashboard for viewing published results
- Contact form storing submissions in the database
- Responsive design for desktop and mobile screens

## Technology Stack
- HTML5
- CSS3
- JavaScript
- PHP 8+
- MySQL / MariaDB

## Database Setup
1. Start MySQL/MariaDB.
2. Create a database named `student_result_management`.
3. Import the SQL file located in `database/schema.sql`.
4. Update the database credentials in `config.php` if needed.

## Default Login Credentials
- Admin: `admin` / `admin123`
- Student: `alice` / `student123`

## Local Run Instructions
1. Place the project in a PHP-enabled web server directory such as `htdocs` for XAMPP/WAMP.
2. Start Apache and MySQL.
3. Open the site in your browser using:
   `http://localhost/student-result-management-system/index.php`
